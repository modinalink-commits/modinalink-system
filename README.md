# Ember Essence — design preview (static prototype)

This orphan branch holds only the static design prototype served at https://ember.modinalink.online.
It is unrelated to the `main` branch (the modinalink.com application) and shares no history with it.

- Bengali version at `/`, English copy at `/en/`.
- `VERSION` + `manifest.txt` drive the server sync: bump `VERSION` and regenerate `manifest.txt` on every update.
- Each update is one commit, so earlier versions stay in this branch's history (tag each release `ember-vX.Y.Z`).
- Sample data only. No secrets, no real payment, SMS or paid API.
